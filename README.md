# míabelle

Handmade crochet & clay-bead jewelry by Mia Johnson in Logan, Utah.

## Live site

Once GitHub Pages is enabled for this repo, the site is published at:

**https://systemsscaleai-gif.github.io/miabelle-website/**

Enable Pages: **Settings → Pages → Source: GitHub Actions**, then merge to `main` (or run the Deploy workflow).

## Local preview

```bash
python3 -m http.server 4173
```

Open http://localhost:4173
